HTML5

HTML5 merupakan standar HTML modern untuk membangun struktur website. HTML menyediakan elemen semantik seperti header, nav, main, section, article, aside, dan footer. Struktur semantik membuat kode lebih terorganisir dan mudah dikembangkan.
